# Створка — сайт-визитка мастера по ремонту окон

React + TypeScript + [Blueprint.js](https://blueprintjs.com) + Vite. Статический сайт, деплоится в GitHub Pages.

## Настройка

Всё, что меняется под мастера, — в одном файле **`src/site.config.ts`**:

| Блок | Что там |
|---|---|
| `brand`, `seo`, `city` | название, заголовок вкладки, описание для поисковиков, зона выезда |
| `contacts` | телефон, e-mail, часы работы, Telegram / MAX |
| `legal` | **реквизиты исполнителя** (самозанятый / ИП / ООО, ФИО, ИНН, ОГРНИП) — попадают в подвал и юр. документы |
| `hero`, `advantages` | тексты главного экрана и преимущества (иконки — [Blueprint Icons](https://blueprintjs.com/docs/#icons)) |
| `masters` | карточки мастеров. Фото кладите в `public/masters/` |
| `prices`, `priceNote` | прайс |
| `faq` | вопросы-ответы |
| `reviews` | настоящие отзывы (`real`) и демо-генерация 3–5★ (`demo`) |
| `form.endpoint` | куда отправлять заявки «Перезвоните» (POST JSON). Пусто — только по телефону |
| `analytics.yandexMetrikaId` | номер счётчика Метрики. Пусто — счётчика и cookie-баннера нет |

Цвета темы — переменные в начале `src/styles.css`.

## Локальный запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
```

## Деплой в GitHub Pages

1. Создайте репозиторий на GitHub и запушьте проект в ветку `main`:
   ```bash
   git remote add origin https://github.com/<user>/<repo>.git
   git push -u origin main
   ```
2. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Готово: каждый push в `main` пересобирает сайт (`.github/workflows/deploy.yml`).
   Адрес — `https://<user>.github.io/<repo>/`.

Свой домен: Settings → Pages → Custom domain, у регистратора — CNAME на `<user>.github.io`.
Пути в сборке относительные, ничего перенастраивать не нужно.

## Чек-лист соответствия законам РФ перед запуском

Сделано в коде:

- **152-ФЗ «О персональных данных»**: политика обработки ПДн (`#/privacy`), **отдельное** согласие
  на обработку (`#/consent`, требование с 01.09.2025), галочка согласия в форме не проставлена
  заранее, без неё отправка заблокирована. В заявку пишется версия согласия.
- **Cookie / Метрика**: счётчик грузится только после согласия в баннере; есть «Отклонить»
  и «Настройки cookie» в подвале. Используется только российский сервис аналитики.
- **Нет трансграничной передачи**: никаких Google Fonts, CDN, иностранных виджетов — всё
  собирается в один бандл.
- **Закон «О защите прав потребителей» (ст. 8–9)**: сведения об исполнителе (ФИО/название,
  ИНН, ОГРНИП) в подвале и документах.
- **ГК РФ ст. 437**: пометка, что цены не являются публичной офертой.
- **38-ФЗ «О рекламе»**: нет «лучший/№1»; цены с «от» и пояснением; **сгенерированные отзывы
  всегда помечены «пример»** — пометку в коде не отключайте, выключайте генерацию.
- **Закон о русском языке (с 01.03.2026)**: весь потребительский текст на русском,
  название — русское слово.

Нужно сделать вам:

- [ ] Заполнить `legal` реальными реквизитами и `contacts`.
- [ ] **Подать уведомление в Роскомнадзор** об обработке ПДн (pd.rkn.gov.ru) до начала сбора
      заявок — обязательно и для самозанятых, штраф за неподачу до 300 тыс. ₽ (ст. 13.11 КоАП).
- [ ] Если включаете форму — `form.endpoint` должен вести на сервер **в РФ** (свой бэкенд на
      российском хостинге, или российский сервис форм). Telegram-боты и зарубежные сервисы
      форм — это трансграничная передача.
- [ ] Перед запуском: `reviews.demo.enabled = false`, добавить настоящие отзывы в `reviews.real`.
- [ ] Заменить фото мастеров (`public/masters/`) — с письменного согласия мастеров на
      публикацию изображения (ст. 152.1 ГК РФ).
- [ ] Гарантийные сроки на сайте должны совпадать с теми, что вы реально даёте.
- [ ] Учтите: GitHub Pages — зарубежный хостинг, он видит IP посетителей. Для визитки без
      формы это обычно приемлемый риск; для полного соответствия 152-ФЗ при сборе заявок
      лучше перенести статику на российский хостинг (папка `dist/` разворачивается где угодно).
- [ ] Проверить название по базе товарных знаков ФИПС перед вложениями в рекламу.

Это техническая заготовка, а не юридическое заключение — финальные документы стоит показать юристу.
